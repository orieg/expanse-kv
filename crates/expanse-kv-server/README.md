# expanse-kv

A multi-threaded, Redis-protocol-compatible key-value store and cache, indexed
by the [`expanse-trie`](https://crates.io/crates/expanse-trie) radix trie.

**Status: pre-release.** This version reserves the crate name. It contains no
server: the binary prints its status and exits non-zero. Follow development at
<https://github.com/orieg/expanse-kv>.
